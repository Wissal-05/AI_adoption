# Services Supportés

Ce document décrit les services et sources de données actuellement analysés dans l'écosystème.

## Booking
Le service Booking est un service transactionnel et logistique. 
Les noms suivants désignent des **MODULES Booking** et non des services indépendants :
- Housing
- Transport
- Catering
- Access
- Repair
- Admin
- Other

## Learning Center
Le Learning Center regroupe divers services académiques et de réservation documentaire. 
Certaines analyses de ce service utilisent les logs web (les journaux serveurs) afin d'extraire la fréquentation et la portée des différentes interactions (les requêtes HTTP).

## Ecommerce Demo
Ecommerce Demo est une plateforme expérimentale d'e-commerce.
Les données du service Ecommerce Demo utilisent comme source la télémétrie Web Analytics (Matomo) pour alimenter les métriques communes d'usage et d'adoption.
